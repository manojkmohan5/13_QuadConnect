A read-only JSON API over public data: approved venues and the match schedule. No student names, NetIDs, emails, check-in codes or feedback are ever returned. Every endpoint is read-only and answers GET.

Responses

Success: 200

Every JSON list has the same shape: count, the filters that were applied, and results. Each result carries a url to its page on the site, built from the model's get_absolute_url().

Bad parameter: 400

An invalid value is never ignored. The response names each bad parameter and how to fix it:

{"error": "Invalid query parameter.",
 "fields": {"min_seats": ["Use a whole number, e.g. min_seats=8."]}}
