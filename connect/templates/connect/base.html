It owns the document shell, the navigation, the palette and the footer, so feature templates only ever fill in a title and a content block. Blocks available to children: title - text inside , also rendered as the page heading subtitle - optional line under the heading content - the page body (required) extra_css- optional per-page styles CSS is inline on purpose. With DEBUG=False, `runserver` will not serve files from /static/, so keeping the stylesheet in the document means production mode renders correctly without adding WhiteHoise or running collectstatic.
